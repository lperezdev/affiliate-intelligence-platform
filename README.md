# Affiliate Intelligence Platform

End-to-end Analytics Engineering project for Affiliate Marketing.

## Project objectives

Build a modern analytics platform covering:

- Affiliate data modelling
- dbt transformations
- Data quality and testing
- Dimensional modelling
- Incremental models
- Slowly Changing Dimensions
- Git and CI/CD
- Databricks
- Semantic Layer
- Metric Views
- AI-powered analytics

## Initial business domain

Advertiser Performance & Growth.
